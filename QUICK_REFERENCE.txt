🔑 AUTHENTICATION FLOW:

  1. Get CSRF Token:
     GET /api/auth/csrf

  2. Register:
     POST /api/auth/register
     Body: {email, password, first_name, last_name}
     Cookie: csrftoken=...

  3. Login:
     POST /api/auth/login
     Body: {email, password}
     ← Response includes: sessionid cookie

  4. Use API:
     GET /api/auth/me
     Headers: X-CSRFToken: ...
     Cookie: sessionid=...

🚀 ADDING A NEW FEATURE:

  1. mkdir -p api/features/my_feature
  2. Create: __init__.py, schemas.py, router.py
  3. Update: api/features/__init__.py (export router)
  4. Update: api/api.py (register router)

  Example:
    api.add_router("/my-feature", my_feature_router, tags=["my_feature"])
